# Credit Scoring Model

## О проекте

Проект реализует модель оценки вероятности дефолта заемщика (Credit Scoring) на основе открытого датасета Kaggle "Give Me Some Credit".  
Модель позволяет по финансовым и демографическим признакам клиента прогнозировать риск невыполнения обязательств по кредиту.

---

## Структура проекта

- `train_model.py` — скрипт для обучения модели (MLP на PyTorch) и сохранения модели и масштабатора.  
- `main.py` — скрипт для запуска инференса модели с вводом признаков через консоль.  
- `src/` — вспомогательные модули: загрузка данных, препроцессинг, описание модели, датасет, обучение.  
- `model/` — папка для сохранения обученной модели и scaler (StandardScaler).  
- `data/` — исходные датасеты (не выкладываются в репозиторий, скачиваются отдельно).

---

## Используемые технологии

- Python 3.8+  
- PyTorch — построение нейронной сети и обучение  
- scikit-learn — препроцессинг, метрики  
- pandas, numpy — обработка данных  
- joblib — сохранение и загрузка масштабатора

## Установка и запуск

1. Клонировать репозиторий:
```
git clone <URL-репозитория>
cd credit-scoring
```

2. Создать и активировать виртуальное окружение (рекомендуется):
```
python3 -m venv .venv
```
```
source .venv/bin/activate # Linux/macOS
```
```
.venv\Scripts\activate # Windows
```

3. Установить зависимости:
```
pip install -r requirements.txt
```
4. Скачать датасет Kaggle [GiveMeSomeCredit]

5. Обучить модель:
```
python train_model.py
```
6. Запустить интерактивный режим прогнозирования:
```
python app.py
```
Введите значения признаков в форму сайта:
- Коэффициент использования незаблокированных кредитных линий  
- Возраст  
- Количество просрочек 30-59 дней  
- Долговая нагрузка (Debt Ratio)  
- Ежемесячный доход  
- Количество открытых кредитных линий  
- Количество просрочек более 90 дней  
- Количество кредитов на недвижимость  
- Количество просрочек 60-89 дней  
- Количество иждивенцев

---

## Архитектура модели

- Однослойный MLP с одним скрытым слоем (64 нейрона, ReLU)  
- Выход — один нейрон с активацией Sigmoid (вероятность дефолта)  
- Оптимизация — Adam, функция потерь — BCE (binary cross entropy)

---

## Результаты

- ROC-AUC около 0.81 на валидационной выборке  
- Низкий риск дефолта, если вероятность меньше 0.33  
- Возможность масштабирования и доработки модели
