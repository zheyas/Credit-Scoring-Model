# Дипломная работа: CreditAI

Тема: **«Разработка модели оценки кредитного рейтинга заемщика с использованием методов машинного обучения»**.

Проект представляет собой веб-информационную систему для банка: сотрудник оформляет кредитную заявку, модель машинного обучения рассчитывает вероятность дефолта заемщика, а результат сохраняется в базе данных вместе с данными клиента, сотрудника, отдела и признаками скоринговой модели.

## Функциональность

- веб-интерфейс на Flask;
- расчет кредитного риска по обученной PyTorch-модели;
- хранение заявок в SQLite;
- справочники пользователей, сотрудников и отделов;
- журнал заявок и карточка каждой заявки;
- административная панель с базовыми показателями;
- API `/api/applications` для выгрузки истории заявок.

## Предметная область и база данных

База создается автоматически при запуске приложения в `instance/credit_scoring.db`.

Основные таблицы:

- `departments` - отделы банка;
- `employees` - сотрудники и их принадлежность к отделам;
- `users` - учетные записи сотрудников с ролями `admin`, `manager`, `analyst`;
- `borrowers` - заемщики;
- `applications` - кредитные заявки, решения и результаты скоринга;
- `application_features` - значения признаков, переданных в ML-модель;
- `audit_log` - журнал действий системы.

## Используемые технологии

- Python, Flask;
- SQLite;
- PyTorch;
- pandas, numpy;
- scikit-learn, joblib.

## Запуск

```bash
source .venv/bin/activate
python app.py
```

После запуска откройте:

- `/` - быстрый расчет риска;
- `/apply` - оформление кредитной заявки;
- `/history` - история заявок;
- `/admin` - администрирование и справочники.

## Машинное обучение

Модель обучается на датасете Kaggle Give Me Some Credit. Используется MLP-классификатор с выходом Sigmoid, который возвращает вероятность дефолта. Для инференса загружаются файлы:

- `model/credit_model.pt`;
- `model/scaler.pkl`.

Повторное обучение:

```bash
python train_model.py
```
